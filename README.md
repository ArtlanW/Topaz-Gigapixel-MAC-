Topaz Gigapixel 简体中文语言包
================================

这是什么
--------
Topaz Gigapixel 官方只有德/英/西/法/日/葡六种界面语言，没有中文。
本语言包把应用内置的「日语」翻译槽位替换为简体中文（1016 条词条全部翻译），
设置界面里的语言名称也会显示为「（简体中文）」。

立即安装
--------
双击「安装中文语言包.command」，输入一次开机密码即可。
装完会自动重启 Topaz Gigapixel，界面即为中文。

恢复英文
--------
双击「恢复英文.command」（会用首次安装时的原版备份还原）。

官方升级后中文失效了怎么办
--------------------------
这是正常现象：Topaz 更新会覆盖应用主程序，中文语言包随之被抹掉。
处理办法：升级完成后，重新双击「安装中文语言包.command」即可。
安装器会自动在新版二进制里重新定位语言包槽位，并用内置的
translations.tsv 翻译表重新生成中文语言包；如果新版新增了界面词条，
新增部分会暂时显示英文，其余照常是中文。想补翻新词条时，
把新词条发给我或按 translations.tsv 的格式自行补充即可。

文件说明
--------
安装中文语言包.command   一键安装（需要管理员密码）
恢复英文.command         还原为官方原版
install.py               安装器本体（通用版，自动定位槽位）
translations.tsv         翻译表（英文原文 → 中文，1016 条）
qml_zh_CN.qm             1.5.0 版对应的成品语言文件（备用）

原理（供了解）
--------------
应用的界面翻译以 Qt QM 格式编译在可执行文件的资源区里。
安装器解析其中的日语语言包，把每条译文换成中文后写回同一位置，
并重算哈希偏移表，最后对应用重新做 ad-hoc 签名。
翻译按「英文原文」匹配，因此升级后老词条都能继续命中。

注意
----
- 原版二进制备份保存在：
  ~/Library/Application Support/TopazGigapixel-zh/Topaz Gigapixel.orig
- 「恢复英文.command」依赖这个备份；不要删除该目录。
- 语言代码对应的是原日语槽位：终端里执行
  defaults write "com.topazlabs.Topaz Gigapixel" uiLanguage -string en
  也可以临时切回英文（无需还原文件）。
